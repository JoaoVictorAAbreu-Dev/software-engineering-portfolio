# Política de segurança

Este repositório contém um portfólio estático. Para relatar um problema de segurança ou exposição acidental de dados, envie uma mensagem para [joaovictoralvesabreu1@gmail.com](mailto:joaovictoralvesabreu1@gmail.com) com a URL afetada, o comportamento observado e passos mínimos para reprodução.

Não inclua senhas, tokens ou dados pessoais de terceiros no relatório. O projeto não oferece garantia de prazo de resposta, mas os relatos serão avaliados e tratados com prioridade adequada.
